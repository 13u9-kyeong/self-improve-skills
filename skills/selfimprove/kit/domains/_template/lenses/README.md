# Lens families — <domain>

## What makes a question usable

1. **It has a direction.** Not "is this X?" but "what is X, and who established it?"
2. **It demands an answer per location**, with a citation or an explicit `n/a` + reason.
3. **It is refutable** — `REFUTED` with a filed defect, or `STANDS` with a ledger.
4. **It is about meaning, not form.**
